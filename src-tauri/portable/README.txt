PeriTray 便携版
==============

直接运行 PeriTray.exe，无需安装。

- 配置 / 缓存 / 日志写在 exe 同目录的 data\ 与 logs\ 子目录：
  换个目录运行 = 全新配置；整个目录拷走 = 配置随身带走
- 升级：用新 exe 覆盖旧 exe 即可，配置保留（同目录前提）
- 前提：系统需已安装 WebView2 运行时（Win11 内置；Win10 绝大多数已随
  Microsoft Edge 预装。缺失时到
  https://developer.microsoft.com/microsoft-edge/webview2/ 下载安装）
- 更新检测会提示新版本；便携版更新需手动下载新 zip 替换 exe
