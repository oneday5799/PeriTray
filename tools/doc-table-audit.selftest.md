# `doc-table-audit.mjs` 判据自测夹具（**故意损坏，勿修**）

本文件是 `tools/doc-table-audit.mjs` 的**可证伪性夹具**：它故意包含四种缺陷，
用来证明四条判据**仍然承重**。由 `tools/verify-final.sh` 调用，期望结果：
**退出码 1、问题恰好 4 个**（若少于 4，说明某条判据已失效）。

用法：

```sh
node tools/doc-table-audit.mjs tools/doc-table-audit.selftest.md
```

| 场景 | 缺陷 | 期望 |
|---|---|---|
| A | 同一张表内列数不一致（表头 2 列，第 8 行 3 列） | **FAIL** |
| B | 行内代码里的**转义**竖线 `\|` | **PASS**（不得误报） |
| C | 行内代码里的**裸**竖线（GFM 下会渲染错位） | **FAIL** |
| D | 行内代码之外、不在引号内的**裸**占位符 `§2.x` | **FAIL** |
| E | `「…」` 内的占位符（引用旧文本，属「提及」） | 仅 **INFO**，不计 FAIL |

---

场景 A：同表内列数不一致 → 应 FAIL

| a | b |
|---|---|
| 1 | 2 |
| 3 | 4 | 5 |

场景 B：行内代码里的**转义**竖线 → 应 **PASS**（不得误报）

| a | b |
|---|---|
| `f(move \|\| g)` | ok |

场景 C：行内代码里的**裸**竖线 → 应 FAIL

| a | b |
|---|---|
| `a | b` | ok |

场景 D：行内代码之外的**裸**占位符 → 应 FAIL

裸占位符：详见 §2.x

场景 E：**引号内**的占位符（引用旧文本）→ 应 INFO，不计 FAIL

引号内占位符：「详见 §2.x」
