# 04 · 前端架构

前端位于 `src-tauri/dist/`，**无构建流程直接编辑**（改完即 dev 热生效），`cargo build` 时嵌入二进制。总量约 7000 行：10 个 JS + 3 个 CSS + 2 个 HTML。

## 1. 双页体系与命名镜像

| | popup（弹出面板） | settings（设置页） |
|--|--|--|
| 入口 HTML | popup.html（73 行） | settings.html（677 行） |
| 生命周期 | 关闭即 hide + WebView Suspend；窗口可销毁重建 | 关闭为 hide 先行 + 3s 延迟销毁 |
| 布局 | WinUI 顶部导航（设备信息/音量控制双标签） | NavigationView 左侧边栏五标签（general/device/audio/shortcut/about） |

脚本组织遵循「**分区在前、入口最后**」+「**命名镜像**」约定：

```
popup 页（4 脚本）                 settings 页（7 脚本）
common.js      ← 共享基础层（两页最先加载）→
popup-audio.js ← 音量控制 tab 分区        settings-general.js   (通用)
popup-devices.js← 设备信息 tab 分区       settings-shortcut.js  (快捷键)
                                        settings-devices.js   (设备过滤)
popup.js       ← 入口（tab 切换/刷新/联动）settings-audio.js     (音量控制)
                                        settings-about.js     (关于)
                                        settings.js           ← 入口（装配 init 系列）
```

## 2. 头注释四要素（强制约定）

每个 JS 文件首部必须写明四要素，示例（popup-devices.js）：

```js
/* popup-devices.js — 主窗口·设备信息 tab：设备列表渲染/右键菜单/连接与托盘项
 * 加载序 3/4（common → popup-audio → 本文件 → popup.js）
 * 提供：loadDevices()（供 popup.js 的刷新按钮/focus 刷新调用）
 * 依赖：common.js（getInvoke/CATEGORIES/getDisplayName/showToast/...）
 */
```

- **文件职责**：一句话 + 功能清单
- **加载序 N/M**：在同页脚本中的位置
- **提供**：对外暴露的函数/全局（跨文件调用的依据，check.mjs 标识符审计依赖此约定成立）
- **依赖**：引用的其他脚本的哪些导出

## 3. invoke 双轨设计（有意设计，勿"统一"）

AGENTS.md 已否决统一化，两者语义差异是弹窗生命周期决定的：

| | popup 页 | settings 页 |
|--|--|--|
| 获取方式 | `getInvoke()` 防御式获取（common.js 提供）：每次调用时检查 `window.__TAURI__` 就绪并缓存 | `const { invoke } = window.__TAURI__.core` common.js 顶层解构，全局词法绑定裸用 |
| 原因 | popup 窗口频繁销毁重建，webview 注入时序敏感——创建早期 `__TAURI__` 可能未就绪，防御式避免 ReferenceError | settings 窗口创建后常驻（延迟销毁），注入必然早于脚本执行 |

迁移/重排加载序时必须保持各自语义。check.mjs 对解构声明做了提取（`const { invoke } = ...` 计入声明池），否则 settings 各脚本裸调 invoke 会误报未定义。

## 4. common.js 公共层 API 清单

加载序 1/N，向 window 挂载全部共享能力：

**主题与材质**
- `CATEGORIES`：设备类型分组定义
- `initTheme() / applyThemeMode(mode)`：深浅主题三态（跟随系统经 matchMedia 监听）
- `applyMaterialMode(material)`：data-material 属性切换 CSS 表现层（配合后端 material-changed 事件）

**invoke 与显示名**
- `getInvoke()`：popup 页防御式 invoke
- `getDisplayName / simplifyDeviceName / formatDeviceName`：设备名解析单一入口（简化 = 取括号内内容；与 Rust 侧 dedup::core_name 语义不同）

**tooltip 族**
- `attachTooltip / attachSessionTooltip / showSessionTip / hideSessionTip`：统一 tooltip 样式、边界避让、滑块 tooltip 保持至鼠标离开

**右键菜单族**
- `registerContextMenu(el, items)` / `clampMenuPosition`（视口钳位防溢出）/ `hideAllContextMenus`
- `createSubmenuShell`：级联子菜单外壳（悬停机制收敛于此，ac5d253）
- `createCheckIcon`：勾选图标单一入口（e14dd9b 收敛）

**对话框与提示**
- `showRenameDialog`（含恢复默认按钮逻辑）/ `createDialog / closeDialog`（WinUI 内容对话框样式）
- `showToast`：WinUI 亚克力样式通知

**快捷键录制**
- `bindShortcutRecorder(input, opts)`：录制器（码表 codeMap 为本文件内部实现细节不对外）；`describeShortcutError` 错误文案收敛
- 内部监听 `shortcut-recorded` 事件同步录制结果

## 5. 两页数据流要点

### popup 页
- 初始化链：common（主题）→ popup-audio（音量 tab 渲染函数定义）→ popup-devices（设备 tab 同）→ popup.js（导航指示条动画、tab 切换、刷新按钮、focus 刷新、`switch-tab` 监听供托盘跳转）
- focus 即刷新：窗口获得焦点自动 reload 设备列表与音频列表
- 实时性来源：`volume-changed`（会话/设备音量推送）、`audio-devices-changed`（默认设备变化）、`config-changed`（配置联动）
- 强制静音记账在 popup-audio.js 维护 buttonMutedDevices 集合（语义见 [07 §7](07-踩坑复盘-高频回归.md)）

### settings 页
- `settings.js` 为装配入口：init 装配各标签页、ComboBox 工厂、NumberBox 焦点装配、更新检测横切流程（runUpdateCheck/renderUpdateInfobar/showUpdateErrorFlyout）
- **导航就绪门**（settings.js:12 settingsNavReady）：get_config 往返期间点击导航先记录、init 完成后补执行——防首次切换播放在空白面板上
- `saveConfig` 是唯一配置写入通道（整包 update_config）；各 toggle/ComboBox 经 bindToggle/createToggle 绑定
- 监听 `config-changed`（外部改动联动刷新）、`settings-tab`（托盘定向跳转标签）、`update-status`

## 6. CSS 架构

### base.css（1186 行）— 共享令牌 + 组件基类
- 设计令牌（CSS 自定义属性）：色板（深浅两套经 `:root` / `[data-theme=dark]` 切换）、圆角、间距、字体尺寸、状态色、图标底色等
- 共享组件类：卡片（card-left/card-actions 布局模式）、按钮族（标准对话框按钮栈）、菜单项行模式、tooltip、toggle 开关、toast、infobar、滚动条、导航指示条——两页复用同一实现，禁止页面私拷贝（553b7ba/e1f459b 两轮组件化收敛的结果）

### 材质表现层协议（恒透明架构的前端一半）
- body 恒透明出生，「默认」材质的不透明观感由 `--page-bg` 实色承担
- `[data-material="mica|acrylic"]` 下背景变半透明，让 DWM 背景板透出
- 后端 `material-changed` → `applyMaterialMode` 只切 data 属性，DWM 操作全在后端

### popup.css / settings.css
仅放页面私有布局规则；公共视觉一律上提 base.css。
