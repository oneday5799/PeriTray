# 01 · 项目概览

## 1. 项目定位

PeriphMonitor 是一款常驻 Windows 系统托盘的轻量级外设监控工具。核心价值：

- **聚合展示**：把分散在设备管理器、声音设置、蓝牙设置里的外设状态（连接/电量/连接类型）聚合到托盘弹出面板
- **快捷操作**：音量控制（设备级 + 应用会话级）、默认输出切换、蓝牙连接/断开、空间音效切换，均可从面板或全局快捷键直达
- **低占用**：无构建前端、事件驱动音频回调、LRU 图标缓存、WebView2 渲染进程休眠（popup 关闭后 Suspend）

平台支持：Windows 10 / 11（x64 与 ARM64），窗口材质（Mica/Acrylic）需 Win10 1809+ / Win11 22H2+。

## 2. 功能全景

### 设备监控（popup「设备信息」标签）
- WMI `Win32_PnPEntity` 查询 + PNPClass 白名单过滤（AudioEndpoint/Bluetooth/HIDClass/Keyboard/MEDIA/Mouse/Monitor）
- 蓝牙设备：BLE 走 GATT Battery Service 读电量；经典蓝牙（BTC）走 windows_pnp 库读电量；连接状态经 WinRT 枚举判定
- 2.4G 无线设备：USB VID/PID 匹配内置库 `wireless_24g_devices.json`，用户可编辑 `wireless_24g_devices_user.json` 扩展（同 VID/PID 用户条目优先），按 type 归入对应分组；**电量暂不支持**（协议不统一，见 README 说明）
- 重命名、隐藏、自定义分组、正则过滤、去重（核心名 + 连接类型）、托盘 tooltip 指定设备显示

### 音量控制（popup「音量控制」标签）
- 输出/输入设备列表：音量滑块（滚轮 1% 微调、精细调节开关后 0.1 步进）、静音、设为默认
- 静音语义三态区分：按钮静音（可锁定变红）、滑块拖零（临时）、强制静音（对需多次点击才能静音的设备一次直达）
- 应用会话音量：真实进程名 + 图标、实时音量推送（`IAudioSessionEvents.OnSimpleVolumeChanged`）、每应用单独指定输入/输出设备（`SetPersistedDefaultAudioEndpoint` 未公开 API）
- 空间音效（实验性，默认关闭）：关 / Windows Sonic / Dolby Atmos / DTS，走未公开的 `CPolicyConfigClient` 接口，按提供应用安装状态动态过滤菜单项
- 设备右键菜单：重命名、隐藏、空间音效、录制输出切换快捷键

### 全局快捷键
- 音量提高/降低/静音、输出设备切换（可多设备共享同一快捷键循环切换）
- 录制器支持 Win/Super 键规范化、符号键显示优化、冲突与不支持键提示

### 系统托盘
- 左键弹窗（位置跟随托盘图标、上浮/下滑动画、恒低于任务栏不遮挡）；右键完整菜单：设备信息、音量控制、音频设备切换子菜单（名称可简化）、系统声音面板族、开机自启、设置、关于
- 图标随深色模式与默认打开页自动切换（注册表变更通知驱动，非轮询）；tooltip 显示指定设备的连接/电量

### 设置页（WinUI NavigationView 双栏布局，五标签）
| 标签 | 主要设置 |
|------|---------|
| 通用 | 开机自启、默认打开页面、硬件加速（WebView2 GPU 开关）、窗口材质（默认/Mica/Acrylic/推荐）、主题模式（跟随系统/浅色/深色）、日志（开关/级别/保留策略）、关机前自动调音量（每设备独立）、更新检测（启动检测/测试版通道） |
| 快捷键 | 各快捷键集中管理与录制、共享循环切换 |
| 设备信息 | 过滤开关与正则、去重、未命名蓝牙显示、分组管理 |
| 音量控制 | 精细调节、静音锁定、强制静音设备选择、简化设备名称、空间音效开关 |
| 关于 | 版本动态读取、更新 infobar 三态（最新/有新版/失败）+ 错误详情浮出面板、帮助链接 |

### 更新检测
GitHub Releases API 对比版本号（正确处理预发布号），启动时 toast 提示 + 关于页持久 infobar。网络层为手写 WinHTTP 客户端（零第三方依赖，中文错误提示分类）。

## 3. 技术栈与选型理由

| 组件 | 选型 | 理由 / 备注 |
|------|------|-------------|
| 框架 | Tauri v2 | 相比 Electron 内存占用小一个量级；Rust 后端便于直接做 Win32/COM 互操作 |
| 前端 | 原生 HTML/CSS/JS（无框架无构建） | 页面规模小（双页十脚本），免打包链路；由 check.mjs 五类校验兜底完整性（详见 [08](08-工程化与工具链.md)） |
| 设备查询 | wmi crate（WMI COM）+ WinRT Bluetooth + 自带 windows_pnp 库（libs/） | windows_pnp 来自 BlueGauge 项目，BTC 电量方案参考同源 |
| 音频 | windows crate Core Audio（公开 API）+ vtable 手调未公开接口 | 默认设备切换 `IPolicyConfig`、应用级设备 `SetPersistedDefaultAudioEndpoint`、空间音效 `CPolicyConfigClient` 均无官方绑定，手写 vtable 偏移调用（详见 [03 §windows.rs/audio.rs](03-Rust后端模块.md)） |
| 网络 | WinHTTP（windows-sys） | 曾用 reqwest+rustls，为减依赖换手写 WinHTTP（a89b0b5），顺带获得中文错误提示能力 |
| 异步 | tokio（Tauri 内置 async_runtime）+ 专职线程若干 | 音频通知 STA 线程、看门狗线程、设备轮询线程、主题监听线程各自独立 |

依赖哲学：**能用系统自带就不引第三方**。全仓第三方依赖极少（wmi/windows/windows-sys/serde/regex/tokio/image/lru 等），换来编译快、体积小、供应链风险低。

```
PeriphMonitor/
├── AGENTS.md                  # 开发约定（提交规范/闸门/架构备忘）——改码前必读

├── .github/workflows/
│   ├── ci.yml                 # push main / PR：check.mjs + fmt + check -D warnings + test
│   └── release.yml            # tag v* 触发：x64/arm64 双架构 NSIS 构建 + GitHub Release
└── src-tauri/
    ├── src/                   # Rust 后端 20 模块（详见 03 章）
    ├── dist/                  # 前端（无构建直接编辑；cargo build 时嵌入）
    │   ├── popup.html / settings.html
    │   ├── styles/ base.css(共享令牌+基类) popup.css settings.css
    │   └── scripts/ common.js + 双页分区脚本（命名镜像）+ 两页入口
    ├── data/ wireless_24g_devices.json   # 内置 2.4G 设备库
    ├── icons/                 # 应用图标 + 托盘四象限图标（深/浅 × devices/volume）
    └── tauri.conf.json
```

## 5. 版本演进史

以 tag 为界概括各阶段主题（细节 commit 可用 `git log --oneline v上一版本..v本版本` 追溯）：

### v1.0.x（2026-07 初）—— 基础盘
设备监控、蓝牙电量、基础音量控制、托盘弹出面板、设置雏形。

### v1.1.x（2026-07 中下）—— 功能扩张期
- **快捷键体系成型**：录制器 → 音量控制快捷键 → 输出设备切换 → 共享循环切换
- **内存优化两轮**：LRU 缓存 / Arc 共享 / 枚举替代 String（517d482）；P0-P2 全面优化并修退出功能（1c10900）
- **更新检测上线**：reqwest 实现（dfc11c4）→ WinHTTP 重写零新增依赖（a89b0b5）
- 关机前自动调整音量（每设备独立）；2.4G 自定义设备文件（用户数据不被更新覆盖）；蓝牙连接从 C#/PowerShell 重写为纯 Rust（1286b22）；WebView2 硬件加速开关（0c785b3）

### v1.2.x（2026-08 上中旬）—— 观感与体验重塑期
- **WinUI 化**：设置页 NavigationView 双栏重构（566a81f）→ 主题三态切换（b0bddf7）→ 主窗口顶部导航（ad97a92）→ 共享组件库 + 设计令牌体系（e1f459b/553b7ba）
- **窗口材质系统**：Mica/Acrylic 引入（5ce1d4d）历经多次回归后收敛为恒透明架构（dd4d022，复盘见 [07 §1](07-踩坑复盘-高频回归.md)）
- **音频深度功能**：会话音量实时推送（4df8e96）、静音锁定（6d79ab5 及系列修正）、精细调节 0.1 步进（29b2c4a）、强制静音（39c7c0d）、应用级设备切换（052d113 修复接口路径打包）、空间音效（8c215e2/a8e37a7 及降级路径系列修复）
- **工程闸门建立**：check.mjs + pre-commit（ba3d407）→ Rust fmt/check 闸门（210a475/19574c4）→ CI 工作流（5ebe6ad）
- **代码收敛潮**：约 20 个 refactor 提交消重复、收可见性、解循环依赖、拆 audio_spatial/update 子模块

### v1.2.11-beta 系列（2026-08 下旬）—— 假死攻坚期 ⭐
休眠/显示器唤醒触发的托盘假死专项治理：诊断埋点 → 事件线程硬化 spawn 化 → 设置页延迟销毁 + 看门狗自愈 → 转发自杀根除 → WebView2 TrySuspend 根治。完整复盘见 **[06 章](06-踩坑复盘-假死.md)**。

### 进行中：feat/24g-battery 分支
2.4G 设备电量支持已在该分支开发（首发 Razer Orochi V2 接收器，c66739a），含 0-255 原始刻度换算修正（5f224a0，OpenRazer 公式印证）与设备列表"对账式渲染"防刷新闪烁（84e7004）。README 中"暂不支持获取电量"的表述将随该分支合并而过时。

## 6. 分支策略

| 分支 | 用途 | 现状（2026-08-24） |
|------|------|--------------------|
| `main` | 主干，push 即触发 CI | 与 origin/main 同步 |
| `dev` | 集成开发分支（约定上） | 当前与 main 无差异 |
| `feat/*` | 单特性分支 | `feat/24g-battery` 进行中；`feat/winui-settings-style` 已合并；`origin/feat/upgrade-windows-crate` 已合并/放弃 |
| `backup/*` | 失败尝试存档，不删除以便考古 | `backup/failed-material-round`：一次失败的材质重构轮次，后被恒透明架构取代（教训见 [07 §1](07-踩坑复盘-高频回归.md)） |

约定：主干提交遵循 [AGENTS.md](../../AGENTS.md) 的 commit 规范（type(scope): 中文一句话）；发版版本号 bump 单独成提交。
