## 2. 后端 → 前端事件

| 事件 | payload | 触发点 | 前端消费 |
|------|---------|--------|----------|
| `config-changed` | `()` | 任何配置写入（update_config/rename/group/material 等） | common(主题材质)/popup-audio/settings/tray 四方联动 |
| `audio-devices-changed` | `()` | 默认设备切换等音频配置变化 | popup-audio 重渲染 + tray 子菜单重建 |
| `tray-devices-changed` | `()` | toggle_device_tray 托盘显示集变化 | tray tooltip 更新 |
| `volume-changed` | `{device_id?, session_id?, volume, is_muted}` | audio_notify 回调链（设备级+会话级） | popup-audio 实时刷滑块 |
| `material-changed` | `&str`（材质名） | set_window_material 第一步（先于 DWM 操作） | 两窗 applyMaterialMode 铺 CSS |
| `switch-tab` | `&str`（tab 名） | popup open_popup/toggle 已存在窗口时 | popup.js 切换标签 |
| `settings-tab` | `String` | open_settings_tab 定向打开 | settings.js 导航跳转 |
| `shortcut-recorded` | 快捷键描述 | 录制完成回传 | common bindShortcutRecorder 回填 |
| `update-status` | `UpdateStatus`（latest/update/error 三态） | check_and_store 完成（启动或手动） | settings-about infobar 渲染 |
| `update-available` | `UpdateInfo` | 启动检查发现新版本 | common toast 提示 |

## 3. 后端内部事件（app.listen，非 Tauri 前端事件）

tray.rs 在 Rust 侧监听（tauri Listener）：

| 事件 | 处理 |
|------|------|
| `config-changed` | 同步 AUTO_START 勾选文本、托盘图标、音频子菜单 |
| `tray-devices-changed` | spawn 更新 tooltip |
| `audio-devices-changed` | 重建音频子菜单勾选态 |

## 4. Device 结构（前后端契约）

```rust
pub struct Device {
    pub name: String,          // 核心名（dedup 后）
    pub status: String,        // "OK"/连接态字符串（WinRT 未覆盖则清空）
    pub battery: Option<u8>,   // 百分比
    pub is_bluetooth: bool,
    pub dt: DevType,           // Mouse/Keyboard/Audio/Display/Battery/Input/Other...
}
```

前端按 `CATEGORIES` 分组渲染；显示名解析顺序：device_names 映射 > simplify 开关处理 > 原始名。
