## 一分钟项目画像

PeriphMonitor 是一款 Windows 系统托盘外设监控工具：WMI + WinRT 蓝牙 + PnP 枚举实时检测音频/USB/蓝牙/电池/显示器设备，提供音量控制（设备级/应用会话级/空间音效）、蓝牙连接管理、全局快捷键。界面为 WinUI 风格的 popup（弹出面板）+ settings（设置页）双页体系。

技术形态：

- **Tauri v2**（Rust 后端 ~6700 行，20 个模块）+ **纯 HTML/CSS/JS 前端**（~7000 行，无构建流程，`cargo build` 时嵌入二进制）
- 大量 Win32/COM 直接互操作：DWM 材质、WebView2 生命周期、未公开的 Core Audio 策略接口
- 工程闸门：pre-commit 五类校验 + Rust fmt/check 零警告 + CI 复跑全套

## 三条最重要的历史教训（详见踩坑篇）

1. **Tauri 主事件循环是单点**——任何在事件线程上执行的同步重操作（Win32 调用、COM 销毁链）挂起都会导致全局假死。铁律：事件回调只做分发，重操作一律 `spawn` 移出。
2. **窗口透明能力在创建瞬间固化进 HWND**——事后 `SetDefaultBackgroundColor` 无法补救，必须"恒透明出生"，观感差异由 CSS 承担。
3. **软件层无法稳定赢过硬件固件的状态同步**——部分音频设备的 HID 代理会回写标量/静音状态，对抗方案必然失败，应引导用户使用显式的强制静音路径。
